# Accesibilidad (A11Y) - Documentación

## Estándares de Accesibilidad Implementados

Este proyecto sigue las pautas WCAG 2.1 Nivel AA para accesibilidad web.

### 1. **Atributos ARIA (Accessible Rich Internet Applications)**

#### aria-label
- Usado para describir elementos sin texto visible
- Botones de navegación: "Video anterior", "Siguiente video", etc.
- Campos de formulario con errores

#### aria-describedby
- Conecta inputs con elementos que describen o validan su contenido
- Ejemplo: `aria-describedby="nombre-error"` para mostrar mensajes de error

#### aria-live
- Para regiones que actualizan dinámicamente (carrusel de videos)
- `aria-live="polite"` - Anuncia cambios sin interrumpir
- `aria-atomic="false"` - Solo anuncia cambios en esa región

#### aria-labelledby y id
- Secciones principales tienen identificadores únicos
- Ayuda a lectores de pantalla a navegar

### 2. **Estructura Semántica**

```html
<!-- Uso correcto de etiquetas semánticas -->
<section role="region" aria-label="...">
<form>
  <label htmlFor="inputId">Etiqueta</label>
  <input id="inputId" />
</form>
<button aria-label="Descripción del botón">
```

### 3. **Validación de Formularios**

- Cada input tiene un `<label>` asociado
- Mensajes de error tienen `role="alert"`
- Inputs con errores tienen `aria-describedby` hacia el error

### 4. **Contraste de Colores (WCAG AA)**

Colores principales del proyecto:
- Primario: `#3E4095` - Alto contraste con fondo blanco ✓
- Secundario: `#F16139` - Alto contraste con fondo blanco ✓
- Texto: `#000000` sobre fondo blanco - Máximo contraste ✓
- Texto gris: `#666666` - Cumple ratio 4.5:1 ✓

### 5. **Keyboard Navigation**

- Todos los botones e inputs son accesibles por teclado
- Focus visible con `focus:ring-2 focus:ring-[#F16139]`
- Orden tabular lógico en formularios

### 6. **Lectores de Pantalla**

- Texto alternativo en imágenes con `title` en iframes
- Descripciones de videos para usuarios con discapacidad visual
- `sr-only` (screen reader only) para contenido adicional

### 7. **Responsive Design**

- Tamaño mínimo de botones: 44x44 px (WCAG 2.5.5)
- Tamaño legible de texto: mínimo 16px
- Espaciado adecuado entre elementos interactivos

## Verificación de Accesibilidad

Para verificar la accesibilidad de la aplicación:

1. **Prueba con teclado**: Presiona Tab para navegar
2. **Prueba con lector de pantalla**:
   - NVDA (gratuito, Windows/Linux)
   - JAWS (comercial, Windows)
   - VoiceOver (macOS/iOS)
3. **Herramientas en navegador**:
   - axe DevTools Chrome Extension
   - WAVE (Wave.webaim.org)
   - Lighthouse (Chrome DevTools)
